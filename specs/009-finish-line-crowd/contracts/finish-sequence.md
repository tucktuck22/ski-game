# Contract: Finish Sequence

The rules `src/render/finish.ts` and `src/ui/game.ts` must satisfy. Each row names its
test.

| #   | Rule                                                                                                                                                                                                                                                                 | Test                                                                                    |
| --- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------- |
| F3  | From each measuring pilot's final state on both courses, the sequence never places the skier below `groundY` (tolerance 0.01). It never produces NaN. It reaches `stopped` with at least 60 ticks of the full hold remaining.                                        | `tests/unit/finish-sequence.test.ts`                                                    |
| F4  | From a synthetic shelf-top state at L (ledge ≥ 0, 50 up, vx 7), and from an airborne state mid-rotation (orientation 2 rad off the slope), the skier lands on `groundY` with orientation equal to the ground slope within 0.01 rad, and never enters a wipeout pose. | same                                                                                    |
| F5  | Skip: a `keydown` with `repeat: true` does not end the hold; a `keydown` with `repeat: false` does; a `pointerdown` does. After skip, `done` is true on the next tick.                                                                                               | same (listener tested against synthetic events)                                         |
| F9  | Under reduced motion the hold is `reducedHoldTicks`, the crowd has no vertical motion and throws nothing, and no snow spray is drawn.                                                                                                                                | same, plus `finish-crowd.test.ts`                                                       |
| F10 | The sequence advances once per simulation tick. Rendering twice without a tick does not advance it.                                                                                                                                                                  | same                                                                                    |
